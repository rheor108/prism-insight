# 독립 품질 평가 실행 오류 복구

평가 도구는 모든 예외를 review_failed로 축약해 실제 원인을 보존하지 않았습니다.
일반 분석 호출의 OAuth 갱신 충돌 복구도 이 별도 CLI에는 적용되지 않았습니다.

- 오류 원문 대신 고정된 error_code와 시도별 상태·소요 시간을 출력합니다.
- 실패 기록은 지정 결과 파일 옆 `.failure.json`에 권한 0600으로 저장합니다.
  기존 결과와 실패 기록은 덮어쓰지 않습니다.
- 명시적인 OAuth 갱신 충돌 문구만 60초 뒤 한 번 재시도합니다.
  인증 만료, 한도, 모델 검증 오류는 재시도나 다른 모델 대체를 하지 않습니다.
- 인증 확인부터 재시도 대기까지 기존 40분 총 제한을 공유합니다.
- 원문 보고서, stderr, 토큰은 진단 기록에 포함하지 않습니다.
- 잠금 파일·인증정보 자동 삭제나 주문은 하지 않습니다.

2026-10-07 최초 실패의 원문은 유실돼 정확한 원인은 미확인입니다.
이후 동일 Opus 5/max 가상 진단은 성공했습니다. 이번 수정이 과거 실패 원인을
소급 확정하지는 않습니다. 운영 증거 평가에는 사용자가 구체적으로 승인한 자료만 사용합니다.
