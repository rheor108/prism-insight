# 2026-10-02 보고서·평가 출력 복구

10월 1일 디아이 기업 개요는 호출 성공 후 완전성 검증에서 실패했습니다.
삼성전기·에코프로에이치엔 요약 평가는 Claude 출력 형식 오류로 두 시도 모두 실패했습니다.
과거 원문을 저장하지 않았으므로 실제 잘못된 필드나 자료 부족 원인은 확정하지 않습니다.

## 변경

- Claude 구조화 응답은 `answer` 안에 JSON 객체를 직접 반환하고, 평가 필수 필드를
  CLI 출력 스키마에서 검증합니다. 부모 실행기로 반환할 때만 문자열로 직렬화합니다.
- 도구 요청은 빈 answer와 calls 배열, 최종 응답은 평가 객체와 빈 calls 배열이어야 합니다.
  이 관계는 로컬에서도 검증합니다. Claude가 거절하는 최상위 조합 스키마는 사용하지 않습니다.
- 출력 형식 실패의 기존 최대 두 시도를 유지합니다. 진단은 JSON 구문 오류,
  스키마 검증 종류, CLI 구조화 재시도 소진으로 구분합니다. 원문은 기록하지 않습니다.
- 보고서 검증은 빈 본문·임시 문구·자료 부족·상위 실패를 구분합니다.
  보고서의 기존 최대 두 시도 중 재시도에 검증 사유와 독립 출처 확인 지시를 추가합니다.
  검증된 자료가 없으면 계속 실패 처리하며, 자료 부족을 성공으로 바꾸지 않습니다.
- 모델·effort·매매 규칙·스케줄은 변경하지 않습니다. 주문과 운영 분석 재실행은 없습니다.

## 검증

회귀 테스트는 가상 응답과 임시 KIS 설정을 사용합니다. 필수 필드 누락 복구,
도구/최종 응답 혼합 거부, 중첩 스키마 참조, 보고서 재시도 및 실패 유지,
인증 실패 무재시도를 검증합니다.
실제 Claude 구독 CLI에서 운영 EvaluationResult 스키마와 가상 문장(2+2=4)을 사용한
검증에 성공했습니다. 운영 보고서·계좌 데이터는 전송하지 않았으며 진단 지표는 /tmp에
분리했습니다. 이 연결 시험은 판단 품질 표본이 아닙니다.

배포 후 실제 새 배치에서 재발 여부를 관찰해야 합니다. 원천 자료 자체의 부족이나
공급자 장애까지 이 변경으로 해결된다고 보장하지 않습니다.
