# 국내 보고서 가격·거래량 시점 구분

## 재현 근거

9월 22일 및 10월 7일 독립 품질 평가에서 오전 보고서가 당일 OHLCV의
Close를 확정 종가, Volume을 종일 거래량처럼 표현한 사례가 반복됐습니다.
10월 7일 빛과전자 보고서는 장중 누적 18,960,000주를 종일 거래량과 비교했고,
이후 다른 섹션에는 더 늦은 장중 누적치가 나타났습니다. 숫자 자체를 바꾸거나
임의로 종일 거래량으로 환산하면 안 됩니다.

## 적용 범위

국내 주식·지수의 **보고서용 Markdown 입력과 기술/시장 분석 표현**을 수정합니다.
원천 OHLCV 숫자, 행, DataFrame, API/MCP 응답 구조는 유지합니다.
regime 계산, 스크리닝, 매수·매도·손절·예산 조건, 모델·effort·cron은 바꾸지 않습니다.
미국 세션 분류 및 시장 지표 불일치 원인 조사는 이번 PR 범위 밖입니다.

- 수집 시각을 KST로 표시하되 원천 시세 시각과 구분합니다.
- 과거 행은 historical_daily, 당일 행은 same_day_unconfirmed로 표시합니다.
  미래·불명 날짜는 검증 불가입니다. 원천에 확정 여부가 없으므로 시각이
  마감 이후라는 이유만으로 당일 값을 확정 승격하지 않습니다.
- 주식·지수의 사전 수집과 도구 호출 대체 경로 모두 동일한 표현 규칙을 사용합니다.
- 장중 누적치를 전일/평균 종일 거래량과 비교해 일간 감소·탄력 약화를
  단정하지 않습니다. 동일 경과시간·원천 시각을 확보한 비교와 과거 일봉끼리의
  비교는 허용합니다. 시간 비례 외삽을 지시하지 않습니다.
- 잠정 행을 포함한 기술지표는 잠정 지표와 입력 기준일을 표시합니다.

## 검증 및 한계

오전·장 시작 전·마감 이후, KST 날짜 경계, 과거 기준일, 미래·불명 날짜,
원천 불변성, 기존 추정치 메타데이터 보존, 사전 수집/도구 경로의 한국어·영어
규칙을 회귀 테스트합니다. 과거의 유효한 일간 비교를 막는 전역 게이트는 없습니다.

이는 프롬프트와 입력 표시 수정입니다. 모든 모델 출력이 규칙을 준수한다는
보증이나 거래 성과 검증은 아닙니다. 다음 운영 보고서에서 실제 표·본문·결론의
시점 표현을 관찰해야 합니다. 새로운 보고서 발행 차단·매매 차단은 추가하지 않습니다.
