# 검색 품질 비교 — 2026-09-23

이번 4문항 실측에서는 **현재 Codex 경로가 공식 원문 추적과 상세 정보 회수에 강했고, Perplexity 기본 ask는 응답 속도가 훨씬 빨랐습니다.** Codex에서도 사실 오류가 확인됐으므로 검색 엔진 교체만으로 정확성을 보장할 수는 없습니다.

## 비교 조건

- 기준: 2026-09-23 한국시간, 공개 정보 질문 4개. 질문별 최초 1회씩, 총 8회 요청 후 Perplexity 일시적 과부하 1건만 1회 재시도했습니다.
- Codex: 운영 코드 `run_stage('research', ..., web_search=True)`, GPT-5.6 Sol / medium. 운영과 같은 검색 지시문과 JSON 입력 형식을 사용했습니다.
- Perplexity: 설정된 공식 MCP `@perplexity-ai/mcp-server@1.2.0`의 `perplexity_ask`. 실행 당시 도구 설명은 Agent API fast preset이었습니다. 별도 모델·검색 범위·컨텍스트 크기 설정은 넣지 않았습니다. Perplexity Research/Reason이나 웹앱 전체를 평가한 결과가 아닙니다.
- 두 경로에 동일한 질문과 동일한 조사 지시문을 전달했습니다. 실제 운영 경로 비교이므로 내부 프롬프트, 검색 횟수, 모델 연산량을 같게 제한하지 않았습니다.
- 요청은 순차 실행했고 질문마다 공급자 순서를 바꿨습니다. 각 요청의 시험 제한은 300초였으며 제한에 걸린 응답은 없었습니다.
- 실행 중 운영 설정·매매 규칙은 변경하지 않았습니다. 별도 공개 질의만 보냈으며, 실험 메트릭은 운영 로그에서 분리했습니다.
- 평가자가 응답을 보고 공식 발표와 실제 기사 원문을 대조했습니다. 블라인드 평가·반복 실험은 아닙니다. 성공 응답은 검색 정확성 통과를 뜻하지 않습니다.

## 중요한 검증 사례

### 1. FOMC: 수치는 둘 다 맞고 출처 깊이는 달랐습니다

두 응답 모두 9월 16일 미국시간 발표, 목표범위 3.75~4.00%, 25bp 인상을 맞혔습니다. Codex는 발표문과 직전 발표·목록을 연결했습니다. Perplexity는 공식 URL을 찾지 못했다고 밝히고 금융매체 등을 인용했습니다. 공식 자료의 물가 관련 설명과 추론을 두 답변 모두 구분하려 했습니다. [Fed 공식 발표](https://www.federalreserve.gov/newsevents/pressreleases/monetary20260916a.htm)

### 2. 삼성전자: Perplexity의 누락과 Codex의 과도한 단정을 모두 확인했습니다

공식 발표에는 연결 매출 171.5조원, 영업이익 89.5조원, DS 매출 127.5조원, DS 영업이익 89.2조원 및 HBM4 공급 확대·HBM4E 샘플 출하 설명이 있습니다. Codex는 이 요청 항목을 회수했지만 Perplexity는 DS 수치와 HBM 설명을 확인 불가로 남겼습니다. 확인 불가라고 정직하게 표시한 점과, 공개 자료를 찾지 못한 누락은 구분해야 합니다. [삼성전자 공식 발표](https://news.samsung.com/global/samsung-electronics-announces-second-quarter-2026-results)

Codex의 추가 설명 중 메모리사업부 매출도 별도 공개되지 않았다는 주장은 틀렸습니다. 공식 실적발표 자료 7쪽은 메모리 매출 **120.8조원**을 표시합니다. 메모리 영업이익 별도 공개 여부와 메모리 매출 공개 여부를 구분해야 합니다. [공식 실적발표 PDF, 7쪽](https://images.samsung.com/kdp/ir/events/2026/2026_2Q_conference_kor.pdf)

Codex가 추가한 반기보고서 백만원 단위 세부 수치와 공개일은 별도 PDF 접근 실패로 독립 확인하지 못했습니다. 이 항목을 검증 통과로 집계하지 않았습니다.

## 운영 판단

이번 표본만 보면 **현재 Codex 검색을 Perplexity 기본 ask로 전면 복원해야 할 품질 근거는 부족합니다.** 공식 수치와 근거를 자세히 확보하는 작업에는 Codex 경로가 유리했고, 지연 시간이 중요한 짧은 질의에는 Perplexity ask가 유리했습니다. 다만 둘 다 인용 대상 원문을 확인하고, 찾지 못한 정보와 공개되지 않은 정보를 구분하도록 검증할 필요가 있습니다.

자동 전환이나 모델 변경은 적용하지 않았습니다. 일반적인 우열을 결정하려면 실제 종목 질의를 더 다양하게 뽑아 반복하고, 한국 중소형주·공시·영문 뉴스·부정적 사건 등으로 범위를 넓혀야 합니다. 이번 결과는 4문항의 현재 설정 비교이며 과거 9월 10일 당시 품질이나 투자 수익률을 증명하지 않습니다.
