# Claude 구조화 응답 실패 복구

2026-09-28 국장 뉴스 분석과 텔레그램 평가 단계에서 `claude_schema` 오류가
발생했습니다. 당시 기록은 여러 오류를 같은 코드로 분류하고 원문을 저장하지
않았으므로 개별 실패가 스키마 정의 오류인지 생성 재시도 소진인지 확정할 수 없습니다.

Claude의 `error_max_structured_output_retries`와 응답 JSON/스키마 검증 실패는
`claude_output_format`으로 구분합니다. 이 경우에만 동일 모델·effort·스키마로
한 번 재호출하며, 바깥 answer 문자열/calls 배열과 내부 평가 JSON 구분을 명시합니다.
부모 MCP 도구는 유효한 응답 반환 뒤 실행되므로 형식 재시도로 도구를 재실행하지 않습니다.
인증·한도·잘못된 스키마·모델 불일치에는 이 복구를 적용하지 않습니다.

전체 단계의 기존 시간 제한과 결과 스키마/모델 검증을 유지합니다. 복구 실패는
오류로 종료하며 다른 모델이나 API로 대체하지 않습니다. 호출 횟수와 실패 코드를
기록하고 실패 시도 토큰을 알 수 없는 경우 `tokens_complete=false`로 표시합니다.
추가 시도가 생기면 지연·구독 사용량이 늘 수 있습니다.

검증: 실패→복구 성공, 반복 실패 제한, 인증/한도/스키마 오류 비재시도,
부모 도구 루프, 시간 초과 정리 테스트. 실제 배치의 실패 자료는 재전송하지 않으며,
가상 입력 연결 시험은 운영 품질 표본에서 제외합니다.

참고: https://code.claude.com/docs/en/agent-sdk/structured-outputs
